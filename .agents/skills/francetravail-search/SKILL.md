# France Travail Search Skill

Search live job offers from **France Travail** (ex-Pôle emploi) — the French national
public employment service — through its **official "Offres d'emploi v2" API**. Covers
the entire French market (~300,000+ live offers), including offers from partner job
boards that consented to redistribution.

> This is a market-specific skill generated by `/add-portal`. Unlike the HTML-scraping
> portal skills, it talks to a sanctioned JSON API, so results are structured and stable.

## ✅ Official API — credentials required (free)

This skill uses France Travail's **public, documented API**, not scraping. Access is
governed by the terms you accept when registering, not by `robots.txt`. Setup:

1. Create an account at **https://francetravail.io**
2. Create an application in your dashboard
3. Subscribe that application to **"Offres d'emploi v2"**
4. Copy `cli/.env.example` to `cli/.env` and fill in:

```bash
FRANCETRAVAIL_CLIENT_ID=PAR_yourapp_xxxxxxxx
FRANCETRAVAIL_CLIENT_SECRET=xxxxxxxxxxxxxxxx
```

Environment variables of the same names also work and take precedence. `.env` is
gitignored — never commit credentials.

**Rate limit: 3 requests/second.** The CLI backs off automatically on 429/5xx.

## When to use this skill

- Search job openings anywhere in France by keyword, commune, département or région
- Filter by contract type (CDI, CDD, intérim), experience level, recency, or alternance
- Get the full description, required skills and apply link for a specific offer

## Commands

### Search job offers

```bash
bun run .agents/skills/francetravail-search/cli/src/cli.ts search [flags]
```

Key flags:
- `--query <text>` / `-q <text>` — keywords (title, skill, company). Recommended.
- `--location <place>` / `-l <place>` — commune **name** (`"Paris"`, `"Saint-Étienne"`), INSEE code (`69123`), or département number (`75`). Names are resolved automatically against the official commune referential.
- `--departement <n>` / `-d <n>` — département code (`75`, `92`, `2A`, `971`). Overrides `--location`.
- `--region <code>` — région code (`11` = Île-de-France, `84` = Auvergne-Rhône-Alpes, `93` = PACA).
- `--distance <km>` — search radius around the commune (default 10). Requires `--location`.
- `--jobage <days>` — posted within N days. Snapped up to the API's ladder: `1`, `3`, `7`, `14`, `31`.
- `--contract <type>` — `CDI`, `CDD`, `MIS` (intérim), `SAI` (saisonnier), `LIB`, `FRA`.
- `--experience <1|2|3>` — `1` = under 1 year, `2` = 1–3 years, `3` = over 3 years.
- `--alternance` — only apprenticeship / work-study offers.
- `--sort <mode>` — `relevance` (default), `date`, or `distance`.
- `--page <n>` — page number (1-indexed).
- `--limit <n>` / `-n <n>` — cap results; also sets the page size (max 150).
- `--format json|table|plain` — default `json`.

At least one of `--query`, `--location`, `--departement` or `--region` is required.

### Fetch full offer detail

```bash
bun run .agents/skills/francetravail-search/cli/src/cli.ts detail <id|url> [--format json|plain]
```

`id` is the offer id from `search` results (e.g. `190RSQK`). A full
`candidat.francetravail.fr/offres/recherche/detail/...` URL also works. Returns the
description, contract, salary, experience, sector, required skills, languages,
education and apply link.

## Usage examples

```bash
# Data analyst roles in Paris, last week
bun run .agents/skills/francetravail-search/cli/src/cli.ts search -q "data analyst" -l "Paris" --jobage 7 --format table

# Data scientist within 30 km of Paris, CDI only
bun run .agents/skills/francetravail-search/cli/src/cli.ts search -q "data scientist" -l "Paris" --distance 30 --contract CDI --format table

# Junior data roles across Hauts-de-Seine (92)
bun run .agents/skills/francetravail-search/cli/src/cli.ts search -q "données" -d 92 --experience 1 --format table

# Machine learning jobs across Île-de-France, newest first
bun run .agents/skills/francetravail-search/cli/src/cli.ts search -q "machine learning" --region 11 --sort date -n 20 --format table

# Work-study (alternance) data offers in Lyon
bun run .agents/skills/francetravail-search/cli/src/cli.ts search -q "data" -l "Lyon" --alternance --format plain

# Full details for one offer
bun run .agents/skills/francetravail-search/cli/src/cli.ts detail 190RSQK --format plain
```

## Output formats

| Format | Best for |
|--------|----------|
| `json` | Default — programmatic use, passing ids to `detail` |
| `table` | Quick human-readable scanning |
| `plain` | Reading a single offer's full detail (`detail` command) |

JSON search output is `{ "meta": { "count", "page", "total", "location", "query" }, "results": [...] }`.
Each result carries `id`, `title`, `company`, `location`, `date`, `url`, `contractType`,
`salary`, `experience`, `duration`, `alternance` and `rome`; missing values are `null`, never omitted.

All errors are written to **stderr** as `{ "error": "...", "code": "..." }` and the
process exits with code `1`. Codes: `NO_CREDENTIALS`, `AUTH_FAILED`, `NO_CRITERIA`,
`BAD_LOCATION`, `BAD_ARG`, `BAD_FLAG`, `NOT_FOUND`, `RATE_LIMITED`.

## Notes

Portal quirks this CLI absorbs for you:

- **Locations are INSEE codes, not names.** The API will not accept `"Paris"`. The CLI
  resolves names against the `referentiel/communes` endpoint and caches the referential
  in your OS temp directory for 30 days, so the lookup costs one extra request at most.
  Note INSEE codes differ from postal codes (Paris is INSEE `75056`, postal `75001`) —
  both are accepted.
- **`publieeDepuis` accepts only 1, 3, 7, 14 or 31 days.** `--jobage` snaps *up* to the
  nearest allowed value (`--jobage 5` → 7 days); anything over 31 drops the filter.
- **Pagination is a `range` window**, max 150 offers per request and max index 1149. To
  go deeper than ~1150 results, narrow the search rather than paging further.
- **No results is HTTP 204 with an empty body**, not an empty array — the CLI reports
  this as `count: 0`, not an error.
- **`--distance` only applies with a commune**, so it is dropped when you search by
  département or région alone.
- Salary arrives split across two free-text fields and is joined with ` — `; many offers
  have no salary at all.
- `meta.total` comes from the `Content-Range` header and reflects *all* matches, not just
  the page returned.
